# Stories and run protocol

Source of truth for the build: `spec-pw-smart-sharding/`. One story at a time. Each story is one branch, one PR against `main`, one fresh worker.

Decisions (owner, 2026-10-15): float every package and Action to latest and record resolved versions in results; measurement target is `~/opensource/couture-cast` (public); deliverable is this public repo, shaped like `~/opensource/tea-test-review`; history storage is the simplest thing that works; the 10% gate is provisional and raw numbers are always reported; nothing employer-related appears in this repo.

## Protocol

- Coordinator: Kerem session `5c387950-377b-4063-acb0-a211d8f33a3f`. Owner is away; the coordinator merges and decides.
- Workers are Claude peer sessions, one per story, closed when the story merges.
- A story merges only after the worker reports `completed` with green CI.
- Every finding is fixed in the story that found it. The story count may only fall.
- Coordinator rules appended by date below.
- Per-story loop (owner, 2026-10-15): a fresh Claude peer session implements the story and opens the PR. The moment the PR opens, the session summons one Codex peer session (herdr, kind codex, read-only, material defects only) for an adversarial review that runs alongside CI and CodeRabbit, not after them, and fixes every finding from all three. CodeRabbit is addressed, CI goes green, the coordinator merges, then hands the next story to a new Claude peer session. Repeat until S10.
- Merged work gets a Codex review too; real findings are fixed in a fix PR, never filed as a new story.
- couture-cast merges (owner, 2026-10-16): the coordinator may merge PRs into `muratkeremozcan/couture-cast` when CI is green. S5 and S6 are measurement branches and merge nothing. S9 lands the adopted configuration (extra parallelization, the Action) through a normal couture-cast PR that the coordinator merges on green CI.
- Models (owner, 2026-10-16): every Claude peer session and every subagent runs Opus 5.5 at high effort (`spawn-fleet.py --model claude-opus-5-5 --claude-arg=--effort --claude-arg=high`; subagents get `model: opus`). Codex reviewers run GPT-6.1-Sol at high effort, the Codex default.
